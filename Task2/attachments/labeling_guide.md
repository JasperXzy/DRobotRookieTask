# Task2 巡线目标点标注脚本与规范

> 版本：v1.0
> 在正式标注前，使用 100 张试标图片验证本规范。

## 1. 启动脚本

在仓库根目录、`drobot-train` Conda 环境已经激活的情况下执行：

```bash
conda activate drobot-train
python Task2/attachments/track_detection_resnet18/label_image.py \
  --image-dir Task2/data/frames/roi \
  --label-dir Task2/data/annotations \
  --resume
```

`--resume` 会从第一张没有同名 TXT 的图片开始。已有标签不会被删除，重新点击
或按状态键时只覆盖当前图片的标签。

## 2. 标注对象

只标注由完整 `640×480` 图像裁剪得到的底部 ROI：

```text
frame[256:480, 0:640]
```

ROI 尺寸必须是 `640×224`。不要标注已经缩放为 `224×224` 的模型输入。

坐标系：

- 左上角为 `(0, 0)`。
- x 向右增加。
- y 向下增加。
- 合法范围为 `0≤x<640`、`0≤y<224`。

脚本显示的黄色水平线是建议前视带，只影响标注判断，不会写入图片文件。

## 3. 正样本

当画面中存在可以可靠跟随的巡线目标时：

1. 使用鼠标左键点击目标点。
2. 每张图片只能保存一个目标点。
3. 点击期望行驶轨迹的中心，不点击线条边缘。
4. 优先在 `y=80～144` 前视带内选择目标点。

当前建议的前视带中心为 `y=112`。它只用于约束标注一致性，不要求每个点的
y 坐标完全相同。

正样本保存为：

```text
x_roi y_roi 1
```

例如：

```text
318.500 111.000 1
```

坐标是 `640×224` ROI 中的原始像素坐标，不是归一化坐标。

## 4. 弯道和分支

- 左弯和右弯都沿车辆当前应该行驶的轨迹选择中心点。
- 多条线同时出现时，必须依据当前任务路线选择正确分支。
- 仅凭单帧不能判断路线时，查看前后帧和视频上下文。
- 仍然无法判断时按 `N` 标记为负样本，不猜测坐标。

## 5. 负样本

以下情况按 `N` 保存为负样本：

```text
nan nan 0
```

- ROI 中完全看不到可跟随轨迹。
- 赛道严重遮挡，无法可靠定位中心。
- 画面模糊、过曝或过暗到无法判断，但属于车辆实际可能遇到的输入。
- 相机短时抖动，模型应当拒绝使用当前坐标。
- 多条路线无法根据上下文确定。

负样本不能同时包含目标点。负样本参与置信度训练，但不参与坐标损失。

## 6. 拒绝样本

以下图片按 `X` 标记为拒绝样本：

```text
nan nan -1
```

- 图片损坏或解码错误。
- ROI 裁剪错误。
- 与任务无关。
- 明确属于重复数据且决定不保留。
- 数据处理流程本身产生的异常图片。

拒绝样本不进入训练、验证或测试。真实运行中可能出现、且模型需要学会拒绝的
场景应保留为负样本，而不是拒绝样本。

## 7. 未标注与负样本的区别

- 没有同名 TXT：`unlabeled`，尚未标注。
- TXT 为 `nan nan 0`：`negative`。
- TXT 为 `x_roi y_roi 1`：`positive`。
- TXT 为 `nan nan -1`：`rejected`。

禁止将缺少 TXT 的图片自动作为负样本。

## 8. 标签文件格式

每张已标注图片具有一个同名 `.txt` 文件，字段以空格分隔：

```text
x_roi y_roi state
```

| state | 含义 | 坐标 |
| ---: | --- | --- |
| `1` | 正样本 | ROI 原始像素坐标 |
| `0` | 负样本 | `nan nan` |
| `-1` | 拒绝样本 | `nan nan` |

早期脚本写出的两个 `[0,1]` 坐标仍可由当前附件脚本读取并显示，但新标注
统一写成三个字段的原始像素格式。

## 9. 快捷键

| 操作 | 作用 |
| --- | --- |
| 鼠标左键 | 保存正样本坐标 |
| `N` | 保存负样本 |
| `X` | 保存拒绝样本 |
| `A` / `D` | 上一张 / 下一张 |
| `Z` / `C` | 向前 / 向后跳 5 张 |
| `H` | 显示帮助 |
| `Q` / `Esc` | 退出 |

## 10. 复核

- 100 张试标中至少 20 张进行独立复标。
- 正式数据集中至少 10% 进行二次复核。
- 复核必须查看点叠加图，而不只查看 TXT 数值。
- 对分歧较大的样本先讨论标注规则，再决定标签。

## 11. 标注完成检查

- [ ] 图片尺寸为 `640×224`。
- [ ] 正样本为 `x_roi y_roi 1`。
- [ ] 负样本为 `nan nan 0`。
- [ ] 拒绝样本为 `nan nan -1`。
- [ ] 点位于 ROI 范围内。
- [ ] 点符合前视带和路线规则。
- [ ] 不确定样本没有被猜测性标注。
